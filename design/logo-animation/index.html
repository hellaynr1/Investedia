How to use

<link rel="stylesheet" href="assets/logo/logo-anim.css"> <script src="assets/logo/logo-anim.js"></script>
InvLogoAnim.mount(el) plays once (production). InvLogoAnim.mount(el, { loop: true }) loops (demo). Colours, delay and duration are CSS variables on .ila (--ila-orange --ila-bg --ila-charcoal --ila-delay --ila-duration --ila-hold) or options. With reduced motion the finished mark appears with a 160 ms fade.
