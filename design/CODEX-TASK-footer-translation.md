# In-page footer translation

The owner's Safari and Chrome screenshots show the Google `translate.goog` proxy refusing connections. Changing the entry URL still reaches that proxy. Replace that navigation with Google's in-page TranslateElement widget and retain the original page if its service fails. No new design mockup was chosen.

## Acceptance criteria and data map

1. A1: The translator loads only after a user requests a non-English language or returns with Google's existing requested-language cookie. Accepting optional services alone must not load it. Source: existing footer `select` option values and the `googtrans` cookie.
2. A2: Requesting a language loads `https://translate.google.com/translate_a/element.js`, initializes `google.translate.TranslateElement` with source language `en` and the existing six target languages, and dispatches the selected language to its combo. Keep Google's actual widget and attribution visible. Never navigate to Google or `translate.goog`.
3. A3: Resume Google's explicit language choice on later pages. “Show original English” clears only `googtrans` for the supported host/domain variants and reloads the same page. Other account/consent state is untouched.
4. A4: A failed script request leaves the original page usable, restores the language control, and shows “Google Translate could not load…” with retry guidance. A later selection retries rather than reusing a rejected promise.
5. A5: If the provider never initializes, time out after 15 seconds, release the disabled control, and leave the original page open. A stale callback from an older attempt cannot initialize a later request.

Language labels/codes remain the existing options in `assets/ui.js`. Provider UI is generated by Google's widget, not fake translated articles or a locally invented translator. The cookie disclosure in `src/pages/cookies.html` explains the explicitly requested provider and its language cookie.

## Validation

`tests/footer-translation.spec.mjs`: A1–A5 passed at 1440px and 390px with a clearly identified provider-contract fixture. That fixture only records language handoff; it is not evidence that Google's real service translated text.
